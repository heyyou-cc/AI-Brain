# Decisiones del dueño

Para qué sirve: las decisiones del dueño que pesan, para mirar atrás y ver si acertó. El agente las apunta solo, en cuanto el dueño decide (AGENTS.md, punto 11).

**Qué entra:** lo que cambia el rumbo o lo que se va a hacer, cuesta dinero o tiempo, cuesta deshacer, elige entre opciones que se platicaron, o va contra lo que el agente recomendó. **No entra:** la rutina («ok, sigue»), los detalles de forma ni las decisiones del agente.

Si el porqué no quedó claro, se apunta igual con «Por qué: no lo dijo». No se le pregunta solo para llenar esta libreta: si después lo cuenta, se agrega. Nunca se inventa.

La más nueva arriba. Una decisión que se echa para atrás no se borra: se anota debajo cuándo y por qué.

Si el agente apuntó mal una decisión (no la tomó el dueño, o la escribió distinta), tampoco se borra sin rastro: debajo de ella va `- Corregida AAAA-MM-DD: <qué estaba mal> · lo que de verdad dijo: <…>`, y si no era una decisión suya, el título se marca «(no era decisión del dueño)».

**Forma:**

```
### AAAA-MM-DD · <la decisión en una frase>
- Por qué: <sus razones, con sus palabras> (o «no lo dijo»)
- Se descartó: <las otras opciones, si las hubo>
- Cómo sabremos si acertó: <qué mirar y cuándo>
- Revisión: <se llena después, cuando el dueño lo pida>
```

# Lo que el dueño sacó

Para qué sirve: apuntar lo que el dueño pidió que no se vea ni se guarde («eso no», «no veas X», «quita eso»), para que ninguna sesión lo vuelva a abrir ni a meter. El agente lo revisa antes de abrir cada fuente y antes de guardar cada dato.

Forma de cada renglón: `- AAAA-MM-DD · qué: <carpeta, archivo, conector, persona o tema> · dijo: «<sus palabras>» · quité de: <notas de donde se quitó, o «nada guardado»>`
